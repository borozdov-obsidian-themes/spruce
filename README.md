# Borozdov Spruce

A theme from the Borozdov collection. Two faces — light **Sapwood**, dark spruce ink on
warm cream paper, and dark **Duskwood**, the same forest at night, cream ink on a
spruce-dark canvas. Sharp 2px corners on every card, a hairline rim instead of a
shadow, and a single mint glow spent on the one button that matters.

![Borozdov Spruce in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/spruce/main/screenshots/light.png)

![Borozdov Spruce in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/spruce/main/screenshots/dark.png)

## Principles

- **Spruce ink, cream paper.** Sapwood reads as dark spruce ink on warm cream; Duskwood
  flips it — cream ink on a spruce-dark canvas — the same pairing, read in both
  directions.
- **One mint glow, spent once.** Every button, tag and callout stays in ink and muted
  teal. The filled button alone takes the mint pill and its focus ring — the single
  moment the whole page turns to colour.
- **A hairline builds every card.** Callouts, code panes, tables and popovers are the
  same card: a mist fill and a 1px hairline rim at sharp 2px corners, never a shadow.
- **Near-square geometry.** Corners stay a tight 2px everywhere except the one pill
  button, which takes a full round — the theme's only curve.
- **Developer-native type.** The platform's own sans at 400 for text and 500 for
  headings that hold their weight rather than bolding up; no embedded font, no load, no
  flash of unstyled text.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- Callouts, code blocks, tables and popovers drawn as the same hairline-rimmed card
- A mint-glow pill reserved for the primary button, with a 4px focus ring on hover and
  focus
- Tags and property pills in muted teal, with a hairline rim until you land on one
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- A toggle thumb tuned per face so it never disappears against its own track
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No embedded fonts, so the theme stays around 13 KB
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory, as a variant:** this theme ships inside **Borozdov
Trellis**. Install Borozdov Trellis under Settings → Appearance → Themes → Manage, then
the [Style Settings](https://github.com/mgmeyers/obsidian-style-settings) plugin, and
choose **Spruce** under Style Settings → Borozdov Trellis → Variant. The variant brings
this theme's palette, type and corners; its own layout, and its embedded font if it has
one, come with the full theme below.

**The full theme, by hand:** download `manifest.json` and `theme.css` from the
[latest release](https://github.com/borozdov-obsidian-themes/spruce/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Spruce/`, then choose Borozdov Spruce under
Settings → Appearance → Themes.
